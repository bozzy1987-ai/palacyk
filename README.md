# Gościniec w Ratuszu — lokalna koncepcja

Jednostronicowy demonstracyjny redesign. Nieoficjalna propozycja, nie produkcyjna witryna obiektu. Brak płatności i formularzy wysyłających dane. Telefon, mapa i wypożyczalnia to rzeczywiste odnośniki.

## Uruchomienie

```sh
npm install
npm run dev -- --host 127.0.0.1 --port 3000
```

Adres: http://localhost:3000

```sh
npm run build
npm run lint
```
